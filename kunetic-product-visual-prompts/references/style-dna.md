# KUNETIC 产品页视觉风格 DNA

## 一句话

真实、专业、清晰、现代的国际 B2B 新能源设备视觉。产品真实性和信息准确性是底线；构图、场景、镜头和表达方式可以变化。

## 统一品牌气质

- 国际 B2B 工业能源品牌感；
- 产品或工程关系是明确主体；
- 画面干净，信息一眼可懂；
- 不做廉价科技蓝光、赛博朋克、全息 UI 或未来概念城市；
- 不为视觉冲击改变产品结构；
- 同组图片有家族感，但不反复套同一模板。

## 色彩与字体

新增图片文字统一使用：

> 极简无衬线字体，现代工业风，字形清晰、克制、专业。

可选文字与标签颜色：

- 藏蓝色：标题、设备名、稳重信息；
- KUNETIC 品牌蓝色：主要参数和技术重点；
- KUNETIC 品牌红色：少量关键数字或差异；
- 深灰色：次级说明；
- 白色：用于深色标签底；
- 青蓝或青绿色：能源流和系统关系辅助色。

同一张图通常使用 1 种主文字色和 1 种强调色，最多 2–3 种文字颜色。品牌红色不得大面积使用。禁止装饰字体、手写字体、圆润可爱字体、促销粗体、霓虹字和渐变字。

## 视觉模式

### A. Product Commercial Photography

适合产品总览、Hero、核心参数、尺寸和单机/多机展示。

高端工业商业摄影，极简白色、浅灰或干净工业背景，自然克制阴影，真实材料质感。产品是绝对主体，不漂浮、不变形、不像塑料玩具。

### B. Real Application Scene

适合工厂、园区、停车场、农场、矿区、酒店、公寓、光储充、光储柴、弱电网、安装、运输和部署现场。

提示词必须以：

```text
一张由iphone6s随意拍摄的真实照片……
```

开头。表现普通手机现场记录感：自然光、轻微曝光不均、正常手机透视、轻微合理畸变、真实地面和使用痕迹。照片清楚可用，但不是电影广告、建筑效果图或明显 3D 渲染。

### C. Engineering Visualization

适合系统拓扑、能源流、PV / Grid / Load / Generator / EV 关系、多机并联和配置关系。

白色或浅灰背景，3–6 个主要节点，工程线条和箭头准确，信息层级清楚。比说明书美观，但准确性优先。禁止复杂交叉箭头、厚重玻璃卡片和未经确认的控制逻辑。

### D. Feature Concept Visualization

适合液冷、安全、EMS、模块化、扩展、环境适应和项目配置。

真实产品加外部技术线条、图标或注释，一张图只解释一个功能。没有内部依据时，不打开柜门、不透明剖视、不凭空放置电池包、PCS、消防或液冷管路。

### E. Deployment / Scale Visualization

适合尺寸、运输、吊装、多柜部署、占地和产品高大宽厚。

通过真实产品、尺寸线、人物、车辆或建筑辅助表达尺度。不得虚构吊点、叉车孔、部署间距或运输方式。

### F. Multi-Scene Application Composite

适合 Applications 或 Hero 应用方向图。由 2–5 个清晰场景组成，产品结构始终一致，不做密集九宫格。

其中每个真实场景都使用 iPhone 6s 普通手机现场语言。

### G. Factory & OEM/ODM Capability

适合 OEM / ODM、装配、检查、测试、包装、发货、工程协作和项目定制。

同样必须以：

```text
一张由iphone6s随意拍摄的真实照片……
```

开头。像客户、业务员或工作人员在真实工厂随手拍摄：自然工业照明、普通工作服、工人动作自然、设备和物料不过度摆拍。

没有真实依据时，只表达一般制造与 OEM / ODM 能力，不声称工厂面积、员工数、产线数、年产能、自动化程度或认证实验室。禁止未来无人化工厂、无依据机器人手臂、员工列队和夸张库存。

## 统一但不重复

统一的是品牌气质、产品真实性、字体、色彩克制和专业程度。

可以变化的是产品角度、左右关系、背景、镜头、光线、人物、工程线条和信息布局。

避免：

- 全部白底；
- 全部产品居中；
- 全部相同三分之四角度；
- 全部四个参数卡；
- 全部蓝天、草地和光伏板；
- 全部中心辐射图；
- 所有工厂图都是一排产品加两个工人。

## 绝对禁止

- 改变真实产品结构；
- 融合不同型号；
- 虚假客户、认证、奖项、工厂或项目；
- 未确认内部结构；
- 竞品品牌；
- 霓虹、粒子、全息屏、能量爆炸、夸张电弧；
- 传统 PPT 式密集排版；
- 所有图片套同一个模板。
