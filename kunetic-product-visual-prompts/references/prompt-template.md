# KUNETIC 产品页提示词模板

## 单张记录格式

```text
### Image [编号] — [名称]

- 页面位置：
- Product Lab 基本职责：
- 比例 / 尺寸：
- 最终文件名：
- English Alt：
- 主要视觉模式：
- 创意自由度：strict / guided / exploratory
- 参考图及用途：
- 核心表达：
- 图片英文文字：
- 必须保留：
- 禁止出现：

完整生图提示词：

[可直接复制的完整提示词]
```

## 通用提示词结构

按自然语言写成完整文本，包含：

1. 图片任务和比例；
2. 参考图编号及用途；
3. 产品真实性要求；
4. 核心表达；
5. 视觉模式；
6. 构图、镜头和产品位置；
7. 背景、场景、光线和质感；
8. 标签、工程线条和字体；
9. 准确英文文字；
10. 必须保留和禁止内容。

```text

采用高端工业商业摄影风格。产品以{视角}位于画面{位置}，占画面约{比例}。背景为{背景}，使用自然克制阴影和真实材料质感，画面干净、留白充分。

{英文文字或“无”}
```

```text

严格参考用户上传的参考图{编号}中的真实KUNETIC产品。参考图1用于{用途}，参考图2用于{用途}。产品位于画面{位置}，以{视角}呈现，保持真实比例、门板、散热、把手、底座、接口和Logo。

图片中的英文文字：{无或准确短文案}。如有文字，使用极简无衬线工业字体和克制品牌色。

禁止出现：产品结构变化、产品像后期贴图、未来城市、夸张夕阳、霓虹、粒子、虚假客户、项目、品牌和未经确认设备。
```

```text
工厂环境包括：{工作台、普通工具、托盘、包装材料、工人等有依据元素}。工人穿普通整洁工作服，正在自然进行{动作}，不集体看镜头，不摆拍。

新增英文文字使用极简无衬线工业字体，可用藏蓝、品牌蓝、品牌红、深灰和白色克制搭配。

本图不声明未经确认的工厂面积、员工数量、产线数、年产能、自动化程度或认证实验室。

禁止出现：虚构机器人产线、无人化工厂、虚假实验室、员工列队、夸张库存、竞品品牌、霓虹、粒子、全息界面和产品贴图感。

```

## 文字规则

文字必须逐字列出。不要写“添加合适参数”。无文字时明确写：

```text
图片中不添加任何新增文字，仅保留产品上的真实KUNETIC Logo和原有标识。
```

## 完成检查

- 参考图编号和作用明确；
- 比例、构图和核心表达明确；
- 图片文字逐字准确；
- 真实场景使用 iPhone 6s 开头；
- 产品结构和禁止项具体；
- 没有调用生图工具。
