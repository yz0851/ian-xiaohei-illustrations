# KUNETIC 产品页提示词模板

## 核心原则

产品外观以参考图为主，文字只做最小约束。

不要默认枚举门板、门缝、把手、铰链、散热口、接口、底座、警示标签或材质。参考图中没有清楚展示的结构，不要在提示词中点名。

产品主体描述通常控制在 1–2 句话；禁止项通常控制在 5–8 项，只保留与当前图片直接相关的内容。

```text
### Image [编号] — [名称]

- 用户要求：
- 匹配页面槽位：
- Product Lab 基本职责：
- 目标比例 / 尺寸：
- 比例来源：
- 设计比例与历史媒体是否冲突：
- 最终文件名：
- English Alt：
- 对应批准文案：
- 主要视觉模式：
- 创意自由度：strict / guided / exploratory
- 产品参考图状态：当前对话可见 / 仓库可读 / 仅有文件记录
- 行业与设计参考摘要：
- 核心表达：
- 必须保留：
- 禁止出现：

完整生图提示词：

[可直接复制的完整提示词]
```

## 产品参考图写法

### 有可见参考图

优先使用以下简洁表达之一：

```text
参考图1中的真实产品制作这张图片，保持图1产品外观不变，不重新设计产品。
```

```text
提取图1中的真实产品作为画面主体，产品外观严格以图1为准。
```

```text
为图1中的真实产品创建一张……
```

不要同时重复三种写法。

### 没有可见参考图

先说明：

```text
当前仓库只记录了图片文件信息，未提供可直接读取的产品图像。使用下面提示词时，请将已确认的真实产品图片上传为参考图1。
```

然后在提示词中写：

```text
参考图1中的真实产品是唯一产品外观依据。
```

不得用长篇结构描述代替缺失的产品图。

## 图片文案规则

文字必须从匹配槽位的批准资料中提取，优先级为：

1. 图片计划中的 `Image text`；
2. 对应区块批准标题；
3. Eyebrow、Subtitle 或 Intro；
4. 批准设备 Label 和参数；
5. 从批准文案压缩出的短 Label。

不要写“添加合适文案”或自行发明营销主张。

只有 Product Lab 明确写无文字、用户明确要求无文字，或职责明确为纯产品展示时，才写：

```text
图片中不添加任何新增文字，仅保留产品上的真实品牌标识。
```

所有新增文字使用极简无衬线字体、现代工业风。通常采用 1 种主文字色和 1 种强调色，可从藏蓝、品牌蓝、品牌红、深灰和白色中克制搭配。

## 完成检查

- 已先匹配正确页面槽位；
- 已采用该槽位的目标比例；
- 已读取对应批准文案；
- 已说明真实产品图是否可见；
- 产品描述保持简洁，没有用文字补画结构；
- 已完成行业与设计参考搜索，或明确说明无法搜索；
- 图片文字逐字准确；
- 真实场景使用 iPhone 6s 开头；
- 禁止项简短且与当前图片相关；
- 没有调用生图工具。
