# 产品页构图模式与原创规则

## 基础结构类型

每张图选择一个主要结构，不要混太多。

### Product Identity Hero

适合产品身份和 Hero 首图。

画法：单产品正面或三分之四视角，占画面约 55%–75%，搭配一组标题和少量核心参数。可左产品右信息、右产品左信息或居中留白。

### Parameter Focus

适合容量、功率、电芯、防护等级和核心配置。

画法：产品加 3–5 组参数，或一个大数字加少量辅助参数。极简无衬线工业字体，藏蓝/品牌蓝为主，品牌红只强调少量重点。

### Feature Annotation

适合液冷、安全、EMS、模块化和环境适应。

画法：真实产品加外部工程线条、图标或保护层。没有内部依据时，不画剖视和内部位置。

### System Relationship

适合 PV + Storage、光储充、光储柴、Grid / Load / Generator、多能源和并联关系。

画法：中心辐射、左输入右输出、横向能源流或上能源下负载。只保留 3–6 个节点，箭头方向、双向和 Optional 必须准确。

### Real Application Scene

适合工厂、园区、停车场、农场、矿区、酒店、公寓、安装和部署现场。

画法：以“一张由iphone6s随意拍摄的真实照片……”开头，产品在前景或中景，建筑、人物、车辆和能源设备辅助说明应用与尺度。

### Deployment & Scale

适合尺寸、多柜部署、运输和占地。

画法：尺寸线、人物尺度、单机到多机、俯视占地或现场阵列。不得虚构间距、吊点和运输方式。

### Multi-Scene Composite

适合 Applications 和多行业方向。

画法：2–5 个场景，一个主场景加辅助场景，产品使用不同真实视角，场景自然过渡，不做密集九宫格。

### Factory & OEM/ODM Capability

适合制造、装配、检查、测试、包装、交付和工程协作。

可选方向：

- 装配现场：1–3 名工人自然操作；
- 测试质检：工程人员检查产品，不虚构实验室；
- 包装交付：合理数量产品、托盘和包装材料；
- 工程协作：人员在产品旁查看资料和讨论配置。

全部使用 iPhone 6s 普通手机现场风格，不摆拍、不夸张规模。

### Configuration Choice

适合标准配置、Optional、功率/容量选择和 OEM / ODM 输入。

画法：主产品对应 2–4 个选项，标准与 Optional 明确区分。不得把可选设备画成内部标配。

## 原创构图生成法

### 1. 把图片职责变成采购者问题

例如：这是什么产品？核心容量和功率是多少？能接哪些能源和负载？适合什么项目？有多大？能否定制和交付？

一张图只回答一个主要问题。

### 2. 选择最有说服力的证据形式

从产品本身、参数、系统关系、项目现场、尺度、工厂、工程注释和配置选择中选一种主要形式。

### 3. 组合少量构图变量

- 正面 / 三分之四 / 侧面 / 低机位 / 高机位；
- 靠左 / 靠右 / 居中；
- 白底 / 浅灰 / 真实现场；
- 单机 / 多机；
- 无人物 / 工人 / 安装人员；
- 参数标签 / 工程线条 / 无文字；
- 近景 / 中景 / 环境全景。

不要把全部变量堆在一张图里。

## 反重复规则

同组图片避免：

- 超过两张相同产品角度；
- 超过两张相同左右布局；
- 全部白底或全部场景；
- 全部四参数卡；
- 全部蓝天、草地和光伏板；
- 全部中心辐射；
- 全部工人站在产品旁；
- 重复同一卖点。

同类主题也要换表达方式：系统能力可用横向能源流而非总是中心辐射；OEM / ODM 可用装配、质检、包装或工程协作；尺寸可用尺寸线或人物尺度。

## 参考案例规则

参考案例只用于构图、镜头、场景、光线和信息层级。不得复制竞品独特构图、文案、产品、客户项目或未经确认功能。
