It retains the original workflow idea and skill organization, while adapting the task domain and visual system for KUNETIC product-page visual planning and prompt generation.

The original `ian-xiaohei-illustrations/` skill and bundled example assets are retained in this fork as upstream reference material. They are not part of the default execution path of `kunetic-product-visual-prompts/`.

The recurring character "小黑" and the original example images remain part of Ian's visual language and are not used as KUNETIC visual references.
